## Who Is This For?

### Readers
**Start:** [Getting Started — For Readers](GETTING-STARTED.md#for-readers)

Learn to discover content, follow authors, highlight text, create reading lists, and bookmark articles.

### Writers
**Start:** [Getting Started — For Writers](GETTING-STARTED.md#for-writers)

Learn to create and publish articles, format with Markdown, manage drafts, and build your audience.

### Publishers
**Start:** [Getting Started — For Publishers](GETTING-STARTED.md#for-publishers)

Learn to create magazines, curate content, manage categories, and host on subdomains via Unfold.

### Developers
**Start:** [Developer Guide](DEVELOPER-GUIDE.md)

Learn to set up the development environment, understand code structure, contribute, and extend the platform.

### System Administrators
**Start:** [Setup Guide](../docs/SETUP.md) + [Architecture](ARCHITECTURE.md)

Learn to install, deploy, configure, and maintain the platform.
